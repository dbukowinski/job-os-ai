# Próbne rozmowy — dziennik

Jedna próbna rozmowa w tygodniu, stały termin w kalendarzu, ok. 60 minut — aż do prawdziwej rozmowy, a nie jedna dzień przed nią.

**Jak:**
- Z asystentem AI (prompt 16.5 z playbooka), z drugą osobą albo w serwisie z próbnymi rozmowami.
- Jeśli możesz, nagraj rozmowę i odsłuchaj ją następnego dnia. Najczęściej słychać wtedy, że myślisz w ciszy zamiast mówić, co robisz, albo że mówisz za długo.
- Po każdej rozmowie wybierz **jedną** rzecz do poprawy na następny raz.

| Data | Rola / firma | Format (AI / osoba / serwis, nagranie?) | Najsłabsza odpowiedź | Jedna rzecz do poprawy | Poprawione? (data) |
|---|---|---|---|---|---|
| | | | | | |

**Działa, gdy** próbna rozmowa stoi w kalendarzu co tydzień, a każdy wpis ma jedną rzecz do poprawy.
